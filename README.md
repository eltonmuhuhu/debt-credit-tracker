# Debt & Credit Tracker

Mobile-first PWA for tracking loans, friend loans, bills, income and cash-flow forecasts (KES by default).

- Single static page, no backend. Data is stored in the browser's localStorage on each device.
- Installable: open the site on your phone and use "Install app" (Profile tab) or "Add to Home Screen".
- Use **Export backup** regularly; data does not sync between devices.

Hosted with GitHub Pages from the `main` branch root.
